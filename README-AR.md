# NEXA AI — Backend Starter

هذه نسخة تأسيسية قابلة للتشغيل محلياً. لا تحتاج شراء سيرفر الآن لتجربتها.

## 1) المتطلبات
- Node.js 20 أو أحدث
- npm
- قاعدة بيانات PostgreSQL مجانية من Neon (خطواتها أدناه)

## 2) التشغيل على Windows
1. فك ضغط المشروع.
2. افتح مجلد `NEXA-AI-Server`.
3. انسخ `.env.example` إلى ملف اسمه `.env`.
4. أنشئ قاعدة PostgreSQL مجانية على https://neon.tech ثم انسخ connection string إلى `DATABASE_URL` في `.env`.
5. أنشئ أسراراً عشوائية طويلة وضعها مكان `JWT_SECRET` و`ADMIN_API_KEY`.
6. افتح Terminal داخل المجلد وشغّل:
   ```bash
   npm install
   npm start
   ```
7. افتح `http://localhost:3000`.

## 3) تشغيل الواجهة
الواجهة الموجودة في `public/index.html` هي واجهتك الحالية مع إضافة تسجيل الحساب وإرسال رمز الدخول تلقائياً. من الإعدادات:
- Backend URL: `http://localhost:3000`
- اضغط حفظ العنوان.
- أنشئ حساباً أو سجّل الدخول.

## 4) ربط نموذج الذكاء الاصطناعي
الخادم يستخدم واجهة متوافقة مع OpenAI Chat Completions. ضع بيانات مزودك في `.env` على الخادم فقط:
- `AI_BASE_URL`
- `AI_API_KEY`
- `NEXA_MODEL_41`
- `NEXA_MODEL_62`
- `NEXA_MODEL_84`

لا تضع مفاتيح API داخل HTML أو ترسلها في المحادثة. يجب أن تكون أسماء النماذج مدعومة من المزود الذي تختاره. لا توجد مفاتيح مضمّنة في المشروع.

## 5) مستويات NEXA
- `4.1`: المستوى الأساسي، ويتطلب إعداد مزود AI وموديل.
- `6.2`: معطّل افتراضياً لأن سياسة إتاحته لم تُحسم بعد. بعد تحديد السياسة، غيّر `NEXA_62_ENABLED=true`. عند تفعيله، يطبق الخادم حد 10 رسائل يومياً لكل حساب.
- `8.4`: يتطلب صلاحية Premium سارية. لم نربط بوابة دفع بعد. يمكن للمسؤول منح تجربة/اشتراك يدوياً مؤقتاً عبر endpoint الإدارة بعد وضع `ADMIN_API_KEY`، إلى أن تختار بوابة الدفع.

## 6) ما يعمل وما لم يكتمل
- يعمل بعد التشغيل: تسجيل حساب، دخول، جلسة JWT، قاعدة بيانات PostgreSQL، فحص صحة الخادم، حراسة المستويات، عداد 6.2 من جهة الخادم، حماية مسارات API.
- الشات وSuper Agent وخطط التطبيقات/المواقع تعمل بعد إدخال مفتاح وموديل مزود AI.
- توليد الصور والفيديو يرجع 501 عمداً إلى أن نختار مزوداً ونربطه.
- إنشاء APK/تطبيقات كاملة، بناء مواقع فعلية، الدفع، البريد لتأكيد الحساب، استعادة كلمة المرور ولوحة إدارة مرئية: مراحل لاحقة وليست مدعاة أنها مكتملة.

## 7) قاعدة البيانات والنسخ الاحتياطي
قاعدة PostgreSQL تُجهز تلقائياً عند بدء التشغيل. احتفظ بسلسلة الاتصال سرية ولا تشاركها.

## 8) قبل النشر العام
- استضف التطبيق خلف HTTPS.
- غيّر جميع الأسرار الافتراضية.
- اضبط `APP_ORIGIN` على دومين الواجهة الفعلي.
- استخدم تخزيناً دائماً لقاعدة البيانات.
- أضف بوابة دفع موثوقة وسياسة خصوصية وشروط استخدام.
- لا تفتح منفذ الإدارة إلا عبر مفتاح سري محفوظ خارج المستودع.


## 9) نشر مجاني من Android
1. أنشئ حساب GitHub وارفع ملفات المشروع بعد فك الضغط إلى مستودع جديد. لا ترفع ملف `.env` الحقيقي؛ ارفع `.env.example` فقط.
2. أنشئ قاعدة بيانات على Neon: https://neon.tech ، اختر Free، وأنشئ مشروعاً، ثم انسخ connection string.
3. أنشئ Web Service على Render: https://render.com ، واربط مستودع GitHub، واختر Free.
4. Build Command: `npm install`
5. Start Command: `npm start`
6. أضف Environment Variables في Render: `DATABASE_URL`, `DATABASE_SSL=require`, `JWT_SECRET`, `ADMIN_API_KEY`, `AI_API_KEY`, `AI_BASE_URL`, `NEXA_MODEL_41`, `NEXA_MODEL_62`, `NEXA_MODEL_84`, `APP_ORIGIN`, `NEXA_62_ENABLED`.
7. اضبط `APP_ORIGIN` على رابط خدمة Render نفسها (مثل `https://اسم-الخدمة.onrender.com`) إذا كانت الواجهة والخادم من نفس الخدمة.
8. بعد نجاح النشر افتح `https://اسم-الخدمة.onrender.com/api/health` وتأكد من ظهور `ok:true` و`database:connected`.
9. افتح رابط الموقع، ثم الإعدادات، واحفظ رابط Render في Backend URL وسجّل حساباً.

تنبيه: Render Free يوقف الخدمة بعد 15 دقيقة من عدم النشاط، وقد يستغرق الاستيقاظ نحو دقيقة. Neon Free لديه حصص استخدام وحدود موارد تتغير حسب سياسة المزود. هذه مناسبة للتجربة وليست ضماناً لتوفر دائم أو إنتاج تجاري.
